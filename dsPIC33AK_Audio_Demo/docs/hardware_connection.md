# Hardware Connection Guide

## Required Hardware

| Item | Part Number | Description |
|------|-------------|-------------|
| Curiosity Platform Board | EV74H48A | Base development board |
| dsPIC33AK512MPS512 GP DIM | EV80L65A | Plug-in module (DIM) |
| Audio Codec Board | AC328904 | AK4642 audio codec daughter board |
| MIC 2 Click | MIKROE-3445 | Electret microphone with preamp |
| External Speaker | Any 8-ohm | Connected to codec headphone out |
| USB-C Cable | Standard | For programming and UART console |

## Board Assembly

1. Insert the **dsPIC33AK512MPS512 GP DIM** (EV80L65A) into the DIM socket on the **Curiosity Platform Board** (EV74H48A).
2. Connect the **AC328904 Audio Codec Board** to the PICtail Plus connector on the Curiosity board.
3. Insert the **MIC 2 Click** into **mikroBUS Socket 1** on the Curiosity board.
4. Connect an **external speaker** to the headphone/line-out jack on the AC328904.

## Pin Connections

### AC328904 Audio Codec Board (AK4642)

| Codec Signal | DIM Pin | dsPIC33AK Pin | Function |
|-------------|---------|---------------|----------|
| BCLK | SCK1 | RD3 | I2S Bit Clock (1.536 MHz) |
| SDO (to codec) | SDO1 | RD4 | Audio data MCU -> DAC |
| SDI (from codec) | SDI1 | RD5 | Audio data ADC -> MCU |
| LRCK | SS1 | RD6 | Word Select / L-R Clock |
| SCL | SCL1 | RD7 | I2C control bus clock |
| SDA | SDA1 | RD8 | I2C control bus data |
| MCLK | REFO1 | RD10 | 12.288 MHz master clock |
| RESET | GPIO | RE3 | Codec hardware reset (active low) |
| PDN | GPIO | RE4 | Codec power down (active low) |

### MIC 2 Click (mikroBUS Socket 1)

| Click Signal | mikroBUS Pin | dsPIC33AK Pin | Function |
|-------------|-------------|---------------|----------|
| AN | AN | RA0 | Analog audio output |
| SCL | SCL | RD7 | I2C (shared with codec) |
| SDA | SDA | RD8 | I2C (shared with codec) |
| VCC | 3V3 | - | 3.3V power |
| GND | GND | - | Ground |

### UART Console (USB-CDC via onboard debugger)

| Signal | dsPIC33AK Pin | Function |
|--------|---------------|----------|
| U1TX | RH1 | UART transmit to PC |
| U1RX | RD1 | UART receive from PC |

Baud rate: **115200**, 8-N-1

### LED Indicators

| LED | dsPIC33AK Pin | Function |
|-----|---------------|----------|
| LED_STATUS | RC8 | Audio activity (toggles on each DMA block) |
| LED_CLIP | RC9 | Audio clipping indicator |

### Buttons

| Button | dsPIC33AK Pin | Function |
|--------|---------------|----------|
| S1 | RC10 | Cycle demo modes (Loopback/Tone/Visualizer) |
| S2 | RC11 | Cycle effect presets (Flat/Bass/Echo/All) |

## I2C Bus Addressing

Both the codec and MIC 2 Click share the I2C1 bus:

| Device | 7-bit Address | Function |
|--------|--------------|----------|
| AK4642 Codec | 0x12 | Audio codec control registers |
| MCP4561 (MIC 2 Click) | 0x2C | Digital potentiometer for mic gain |

## Audio Signal Flow

```
MIC 2 Click (AN) -----> ADC (RA0) -----> DMA Ch2
                                              |
AC328904 Codec ADC ---> I2S/SPI1 RX --> DMA Ch1
                                              |
                                     [DSP Processing]
                                     Noise Gate
                                     5-Band EQ
                                     Bass/Treble
                                     Echo
                                              |
                                     DMA Ch0 --> I2S/SPI1 TX --> Codec DAC
                                                                      |
                                                              Headphone/Speaker
```

## Power Supply

- The Curiosity Platform Board is powered via USB-C
- The AC328904 codec board is powered from the PICtail Plus connector (3.3V)
- The MIC 2 Click is powered from the mikroBUS socket (3.3V)

## Important Notes

1. **MCLK**: The codec requires a 12.288 MHz master clock on its MCLK pin. This is generated by the dsPIC33A REFO1 output on RD10. Verify this connection is made on your board.

2. **I2C Pull-ups**: The I2C bus requires pull-up resistors (4.7k to 3.3V). These are typically present on the Curiosity board. If not, add external pull-ups.

3. **Codec Reset**: RE3 must be driven high after power-up for the codec to operate. The firmware handles this automatically.

4. **MIC 2 Click Gain**: The default microphone gain is set to mid-range (128/255). Adjust via the `gain` CLI command if audio is too quiet or too loud.
